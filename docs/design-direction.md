# 디자인 방향 — Celestial Record

## 한 문장

출생 순간의 하늘을 신비화하기보다, 검은 관측실에서 정밀한 궤적을 읽는 듯한 **천문 기록지형 에디토리얼 UI**로 표현한다.

## 시각 원칙

- 검정에 가까운 청록 바탕, 미색 본문, 선명한 teal 한 색을 주조색으로 사용한다. 어스펙트 구분에만 coral과 gold를 제한적으로 쓴다.
- 기억점은 hero의 얇은 궤도장이다. Canvas 장식은 고정 seed로 생성되며 실제 천체 위치·SVG 차트 데이터와 완전히 분리한다.
- 큰 serif 제목과 작은 mono 기술 라벨을 대비시킨다. 카드 나열보다 선, 여백, 표 구조로 정보 계층을 만든다.
- 브랜드 이름은 확정 전이다. 임시 표기는 `NATAL` 한 곳에만 두고 `브랜드명 미정`을 함께 표시한다.
- 원형 차트는 실제 ASC 회전, cusp, 행성 longitude를 그대로 유지한다. 색상 외에도 실선·점선·기호로 차이를 보존한다.

## 상호작용과 접근성

- hero의 유일한 CTA는 실제 입력 폼으로 이동한다.
- 궤도 애니메이션은 작은 광점만 움직이고 particle 수와 device pixel ratio를 제한한다. `prefers-reduced-motion`에서는 정지 화면만 그린다.
- 모든 입력은 항상 보이며 label과 기존 id/name을 유지한다. 390px 화면에서 액션은 2열 또는 전폭으로 재배치한다.
- 해석용 Markdown은 사용자가 직접 복사할 때만 클립보드로 이동하며 자동 전송하지 않는다. 미리보기 dialog는 키보드와 screen reader가 읽을 수 있는 native `dialog`를 전제로 한다.

## 금지선

- 장식 궤도를 계산 차트로 설명하지 않는다.
- 외부 font, CDN, 이미지, 런타임 의존성을 추가하지 않는다.
- 브랜드 확정 전 레퍼런스 이미지의 이름이나 식별 요소를 차용하지 않는다.
- 미구현 해석 기능이 활성화된 것처럼 보이는 버튼이나 문구를 만들지 않는다.
