# Heliaca 브랜드 가이드

## 이름과 의미

**Heliaca**는 해가 떠오르기 직전 또는 빛과 함께 천체가 모습을 드러내는 순간을 연상시키는 이름이다. 이 서비스에서는 운명을 예언한다는 의미가 아니라, 출생 순간의 하늘을 계산 가능한 좌표로 드러내고 자신을 읽는 하나의 관점을 제공한다는 의미로 사용한다.

## 핵심 문장

- 메인 카피: **태어난 순간의 빛으로, 나를 읽는 새로운 시선.**
- 태그라인: **당신의 시작을 비추는 별의 지도.**
- 제품 설명: 출생 시각과 장소를 바탕으로 검증 가능한 네이털 차트를 계산하고, 그 결과를 해석 가능한 형태로 정리한다.

카피는 경향, 관점, 가능성을 말한다. 성격이나 미래를 단정하거나 의료·법률·재정 결정을 대신하는 표현은 사용하지 않는다.

## 심볼

심볼은 세 요소로 구성한다.

1. 흰 수평선: 출생이라는 시간의 경계
2. teal 반원과 중심 광점: 수평선 위로 드러나는 첫 빛
3. 세 개의 짧은 광선과 아래 곡선: 관측 가능한 상승과 이어지는 천체 궤도

심볼 원본은 [`web/assets/heliaca-mark.svg`](../web/assets/heliaca-mark.svg), 수평 조합 로고는 [`web/assets/heliaca-logo.svg`](../web/assets/heliaca-logo.svg)다. SVG의 viewBox와 선 비율을 유지하고 회전하거나 별자리·황도 기호를 추가하지 않는다.

## 색과 타이포그래피

- Void `#020606`: 주 배경
- Ink `#EEF5F1`: 로고와 본문 전경
- Heliaca teal `#58DBC8`: 떠오르는 빛과 주요 행동
- First-light teal `#91F0DF`: 작은 광점과 강조

큰 제목은 고전적인 serif, 인터페이스 본문은 humanist sans, 계산 메타데이터는 mono 계열을 사용한다. 외부 폰트 다운로드 없이 운영체제의 적절한 fallback을 사용한다.

## 사용 원칙

- favicon과 작은 아이콘에는 mark만 사용한다.
- header처럼 가로 공간이 충분한 곳에는 wordmark 조합을 사용한다.
- 검은색 또는 매우 어두운 청록색 배경 위 사용을 기본으로 한다.
- 로고 주변에는 최소한 광점 지름 4배의 여백을 둔다.
- ‘정확한 운명’, ‘미래 예측’, ‘당신은 반드시’ 같은 결정론적 문구와 함께 사용하지 않는다.
